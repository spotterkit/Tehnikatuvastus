# Tehnikatuvastus (Equipment Recognition)

Tehnikatuvastus is a non-commercial educational tool for practising military equipment recognition. It runs in the browser and can be installed for offline use (PWA). The interface is in Estonian.

## Images and data

- Most photos come from Wikimedia Commons. The author and licence of each photo are shown on its Commons page, linked below the image in the app.
- The remaining images come from publicly available online sources. They are used for non-commercial educational purposes, and copyright remains with the original authors.
- Sources for the technical data (TTA) are listed for each model. Texts taken and translated from Wikipedia are available under CC BY-SA 4.0.
- Symbol SVG parts come from Esri joint-military-symbology-xml (Apache License 2.0, see `images/symbols/LICENSE.txt`).
- Oswald font: SIL Open Font License 1.1 (`fonts/OFL.txt`). qrcode-generator: MIT License.

Images and third-party data are not covered by any licence of the code in this repository. A full overview is available in the app under "Litsentsid ja allikad" (Licences and sources).
