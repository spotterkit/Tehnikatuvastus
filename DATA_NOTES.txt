TTA KIRJE
  "BMD-2": {
    "status": "unverified",                  ← alati; TTA-d ei märgita kontrollituks
    "values":   { "maxSpeedRoad": 80, "atgmRange": { "min": 70, "max": 4000 }, ... },
    "warnings": { välja_võti: "tekst" },     ← kollane märge (nt allikad lahknevad)
    "notes":    { välja_võti: "tekst" },     ← hall täpsustus
    "sources":  [ { "name": "...", "url": "https://...", "retrieved": "AAAA-KK-PP" } ],
    "verifyAgainst": { "name": "U.S. Army ODIN / WEG", "url": "https://odin.t2com.army.mil/WEG/Asset/..." }
  }
- Lisa ainult need väljad, mille väärtus on teada. Tühja/"—" välja ära kirjuta.
- REEGEL: väärtus peab olema allikas kirjas selle masina kohta. Ei tuletata ega arvata.
  Üldise nimega mudel (nt T-72, T-80, T-62): sobib esindava variandi andmestik (nt ODIN/WEG T-80BV);
  variant on näha allika nimes ja vajadusel märkuses "Andmed: ...". Täpsustusi variantide kaupa ei taotleta.
  Konkreetse variandi nimega mudel (nt T-90M, BMD-4M): eelistatult selle variandi andmed.
  Kui ei leia, jääb väli lihtsalt ära.
- ODIN/WEG vs Wikipedia: eelistatakse ODIN/WEG väärtust; suure lahknevuse korral "warnings" märge.
  Erand: kui ODIN/WEG on ilmselgelt kopeeritud teiselt mudelilt (nt T-90M mootor = T-90A oma),
  jääb Wikipedia väärtus ja lahknevus kirjutatakse "warnings" alla.
- Arvud on numbrid (80, mitte "80km/h"); ühik tuleb sõnastikust ja kuvatakse kohe numbri järel (80km/h).
  Laskekaugus: "range" {min, max}.
- Tekstides kirjuta ühik samuti tühikuta: 30mm, 7,62mm, 1500m.
- Uus väli (nt suurtükile laskekaugus, MLRS-ile rakettide arv): lisa üks rida tta-fields.js-i.
- Suurtükid / miinipildujad / reaktiivsuurtükid (rc12):
  caliber (mm), weightKg (järelveetavad, kg), chassis (tekst), launchTubes (tk), salvoTime (s),
  firingRangeMin, firingRange (põhimoon), firingRangeBB (base bleed mürsk, BB),
  firingRangeExt (rakettkiirendiga mürsk, RAP – Militermi eelistatud termin), firingRangeGuided (juhitav) – kõik km;
  Base bleed: Militermis eestikeelset terminit pole (8.10.2026) – kasutatakse "base bleed mürsk (BB)".
  directFireRange (otsetule kaugus, m). Moona nimi (nt 9M22U, OF45) kirjuta "notes" alla.

WHAT-PILDI LISAMINE / ASENDAMINE (soovitatav viis)
1. Ekspordi PowerPointist PNG/JPG nimega <cat>_what.png (nt BMP-2_what.png) kausta images/what/.
   Asendamisel kustuta enne vana <cat>_what.webp (muidu skript jätab vahele: "on juba olemas").
2. what.js-is "image": "images/what/BMP-2_what.png" (uue mudeli puhul; asendamisel on viide juba olemas).
3. python tools/optimize_what_images.py          → vaata, mis muutuks
   python tools/optimize_what_images.py --apply  → WebP (max 1000 px, kvaliteet 70), viited uuendatakse,
                                                    originaal kustutatakse kaustast
4. node check_release.js .
- Tulemus: ~100 KB pildi kohta (BMD-2: 181 KB → 99 KB; otse slaidi PNG: 1,3 MB → ~115 KB).
- check_release.js annab märkuse, kui WHAT-pilt pole WebP või on üle 250 KB.

ODIN/WEG PDF-EKSPORT (eelistatud allikas)
- ODIN-is mudeli lehel: ekspordi PDF. Saada PDF-id (võib ka mitu korraga / zip-ina).
- PDF-ist loetakse väljad automaatselt (System, Dimensions, Automotive, Main Weapon System, Ammunition).
  "INA" = andmed puuduvad → välja ei lisata. Allikaks ODIN/WEG link; status jääb "unverified".
- WEG lisab maastikuläbivuse: gradient (tõusunurk %), sideSlope (külgkalle %), verticalStep (m),
  trench (kraavi laius m), fording (veetakistuse sügavus m, ilma ettevalmistuseta; ettevalmistusega → notes).
- Tankid (ODIN/WEG, 8.10.2026): mainGunRange = APFSDS efektiivne laskekaugus, HEAT/HE kaugused notes all.
  "Speed, Average Cross" ei ole max maastikukiirus – maxSpeedOffroad'i sellest ei täideta.
- Pioneeri- ja õhutõrjetehnika (rc21, tta-fields version 5): uus sektsioon "Eriotstarbeline varustus"
  (mineLaying, mineCapacity, mineClearing, specialEquipment) ja õhutõrjeväljad samMissiles, sensors,
  samRange / samAltitude (range, m), cannonAltitudeAir. Kirjed: GMZ-3, UMZ, UR-77, IRM, 2S6 Tunguska
  (2S6M andmed), STRELA-10/SA-13 Gopher. UMZ ODIN-i kandevõime ja MT-LBu soomus = teised variandid → warning.
- rc22: PRP-4 (PRP-4A Argus andmed), ZOOPARK-1, 9P149 Shturm-S, 9P157 Krizantema-S, 9P162 Kornet-T.
  ODIN-i vead → warning: Krizantema laius 6,715m, Shturm-S 9M120 Ataka (= Shturm-SM) ja MT-LB andmed,
  Kornet-T mass 14,1t, Zoopark avastuskaugused (allikad lahknevad).
- TTA võrdluses on mudeli nime all mudeli täpsustus (entry.type, nt "Pioneeriluuresoomuk"), mitte "kontrollimata"
  – disclaimer on niikuinii tabeli kohal (rc22).

WHAT: MÄRKUS JA ALUSPLATVORM (rc10)
- "note": "tekst"  → roheliste äärtega infokast WHAT-vahekaardi ülaosas (nt BTR-60 baasversioon).
- "related": [ { "label": "Näiteks kasutavad BMP-1 alusplatvormi",
                 "models": [ { "name": "PRP-4A", "cat": "PRP-4" }, { "name": "BMP-1AM" } ] } ]
  · Silt algab alati "Näiteks kasutavad …" – nimekiri on näited, mitte täielik loetelu (koolon lisatakse ise).
  · "cat" olemas ja mudelil on pildid → klikitav, avab selle mudeli pildid.
  · "cat" puudub (või mudelil pole pilte) → kuvatakse tekstina (punktiirjoon).
  · "cat" puudub → äpp otsib mudeli NIME järgi (rc15). Kui lisad äppi uue mudeli (nt BMM-3), muutub
    nimi kõigis WHAT-ides ise klikitavaks. "cat" on vaja ainult siis, kui nimi ja mudeli cat erinevad
    (nt "PRP-4A" → "PRP-4") või nimele sobib mitu mudelit.
- Mudelilt mudelile liikudes ilmub üles "‹ <eelmine mudel>" nupp; telefoni tagasi-nupp teeb sama.

KUREERITUD TEST (rc18–rc19) – õpetajale, fail curated-test.js
- Avalehel Testid all: "Kureeri test (õpetajale)" ja "Ava salvestatud test". Nõuded: Kureeritud_test_nouded.md (N1–N28).
- Ülemine riba "1 Seaded · 2 Pildid · 3 Kinnita ja salvesta" on klikitav (3 = kinnita). "‹ Tagasi" = eelmine samm,
  sammust 1 avalehele. Brauseri/hiire tagasi-nupp teeb sama (oma history kirje), ka pärast printimisakent.
- Sammus 2 on üleval kleepuv riba: küsimuste arv, "Testis x / y" ja "Kinnita test ›". Salvestamata testist lahkudes (ka TEHNIKATUVASTUS pealkirja kaudu) küsitakse kinnitust.
- Samm 1: testi nimi (failinimes ja projektori avaekraanil; tühi → "Tehnikatest <kuupäev>"), liikumine
  (käsitsi / automaatne; vaikimisi pilt 15 s, kirjutamine 10 s).
- Samm 2: küsimuste arv (eelvaate päises); "Täida piltidega": kogus kategooria kaupa, "Kõik" / "0" igal real,
  "Tühjenda kõik". Linnuke "Üks pilt mudeli kohta": peal → maksimum = mudelite arv; maas → maksimum = kõigi piltide arv
  ja pildid jaotatakse ühtlaselt ringide kaupa (igast mudelist üks, siis teine ring...), sama pilt ei kordu.
  Kategooria nimele klõps näitab mudeleid koos piltide arvuga; linnukesega saab mudeli välja jätta.
  Kui valitud rohkem kui vabu kohti, pakub arvu suurendada. Eelvaates "pilt 2/5" ja "mudel testis 3×".
  "+ Lisa pilt käsitsi" (mis tahes mudeli mis tahes pilt), eelvaates Vaheta pilt / ↑ / ↓ / ✕, Sega, Kategooriate kaupa.
- Samm 3: järjest 1) Salvesta test (.html), 2) Prindi vastuste leht, 3) Prindi õpilase leht; siis "Alusta testi".
  Linnukesed on seotud testi sisuga: kui test pärast salvestamist muutub, kaovad linnukesed ja samm 3 hoiatab,
  et vana fail ja vanad lehed ei kehti. Muutmata test säilitab linnukesed ja kuupäeva.
  Lehed tulevad brauseri printimisaknast (ka "Salvesta PDF-ina"); PDF-i faili nimeks pakub brauser lehe pealkirja.
- Testifail <nimi>_<kuupäev>_<arv>kys.html (nimeta: Tehnikatest_…): sees JSON (id="tehnikatuvastus-test") ja suunamine
  <äpi aadress>#kureeritud=<base64url JSON>. Topeltklõps avab äpi koos testiga (vajab internetti Commonsi piltide jaoks).
  Äpi aadress = see, kust test salvestati (GitHub Pages või kohalik index.html). Failis on vastused – õpilastele ei jagata.
- Avamisel kontrollitakse, kas iga küsimuse mudel (cat) ja pildifail on veel CATEGORIES-is. Puuduv → samm 2, vaheta.
- Projektor: start → pilt + suur number → "Kirjuta vastus" → järgmine → "Test läbi". Klahvid: → ↓ PageDown Enter edasi,
  ← ↑ PageUp tagasi, tühik = paus (automaatne) / edasi (käsitsi), F = täisekraan. Esc väljub ainult täisekraanist,
  test jääb alles; ✕ ja tagasi-nupp küsivad kinnitust. Failinime, allikat ega vihjeid ekraanil ei ole.
- "Test läbi" ekraanil: "Näita vastuseid" (rc20) – kõik õiged vastused ühel ekraanil (nr. mudel – täpsustus),
  "‹ Tagasi" viib "Test läbi" juurde, "Sulge" lõpetab.
- NB: moodulis alati window.history (index.html globaalne `let history` varjab brauseri oma).
- localStorage'it ei kasutata. Olemasolevat testi, harjutamist ja kuldvillakut moodul ei muuda.
